How to create and install an app with AppForge.

01

Enter your website

Use a public HTTPS website URL. Some websites block being displayed inside mobile apps, so test the preview first.

02

Customize the app

Set the app name, Android package ID, version name and version code, description, launcher icon, splash logo, theme and splash colors, orientation, display mode, status-bar color and icon style, pull-to-refresh, navigation visibility, pinch-to-zoom, keep-awake behavior and screenshot protection.

03

Build the APK

Tap Build Installable APK. The connected GitHub Actions workflow compiles the Android application in the cloud.

Installing on Android

When the build completes, download the APK on your Android device, open it, and allow installation from your browser or file manager if Android asks. Only install APKs from sources you trust.

Sharing your app

After a successful build, use “Copy public download link” to copy a shareable URL. Anyone who has that URL can download the APK without signing in. The link stays available while the corresponding GitHub release and asset remain published.

Build requirements

The site must be connected to GitHub Actions and configured Vercel environment variables. This builder creates Android APKs that load the supplied live HTTPS website, so the app needs internet access and the website must permit WebView embedding. Keep-awake, zoom, status-bar styling and screenshot protection are native Android settings. iPhone/iPad installation needs a separate Apple build and signing process.
