APPFORGE HELP CENTER

How to create your Android app

Follow these steps from your first sign-in to installing the finished APK. You do not need to know how to code.

BEFORE YOU START

What you need

  • A website that is already online and opens with https://.
  • An AppForge account. Create one with your email and verify the code sent to your inbox.
  • An Android phone or computer to download the APK after the build.
  • Optional: a square app icon and a separate opening-screen logo.

AppForge packages your live website inside an Android app. It does not copy your website files or make the website work offline. The app needs an internet connection.

01

Create your account

Open Account, choose Create account, enter your name, email and password, then enter the verification code sent to your email. If you already have an account, choose Sign in.

Open Account ↗
02

Enter your website address

Open Create App and paste the full public HTTPS address, for example https://example.com. You can do this as a guest. Tap Preview website to check that it opens. A site may work in your browser but block embedded WebView apps; if it does, its owner must allow the app's WebView access.

Open Create App ↗
03

Set up your app identity

Choose the name people will see under the Android icon. Keep the package ID in a format such as com.company.myapp; it must be unique for each different app. Set a version name and a positive version code. Increase the version code when publishing an update to an existing app.

04

Customize the appearance and behavior

Upload an optional home-screen icon and opening-screen logo, then choose your colors, screen orientation and display mode. The advanced switches control pull-to-refresh, navigation buttons, zoom, keeping the screen awake and screenshot protection. The live phone preview shows the opening-screen logo and background.

05

Build and follow progress

Tap Build installable APK once. AppForge sends the settings to its secure build service, and GitHub builds the Android app in the cloud. Keep the build page open to see progress, or return later through My Apps. A build can take several minutes.

06

Download and install the APK

When the status says APK ready, tap Download APK. On Android, open the downloaded file and follow the installation prompts. If Android asks, allow your browser or file manager to install apps from that source. Only install APKs you trust.

YOUR WORKSPACE

Find your saved apps

Sign in and open My Apps to see projects saved to your account. Builds in progress refresh automatically while the page is open. You can also tap Refresh now. Build history is private to your account.

Important information and troubleshooting

My website preview does not open.

Check the address, make sure it starts with https://, and confirm the website is public and online.

The app opens to a blank page or says the site cannot be displayed.

The website may block Android WebView, require a browser-only feature, or depend on a browser extension. Ask the website administrator to allow embedded WebView access and test the site on an Android device.

I did not receive the email verification code.

Check Spam/Junk and confirm the email address. If it still does not arrive, the platform owner must check the Supabase email template and SMTP delivery settings.

My build failed.

Check that the website is public, the package ID is valid and the logo files are supported. Try again. If repeated attempts fail, the platform owner needs to inspect the private build logs and service configuration.

Can I publish the APK directly to Google Play?

AppForge currently creates a test/installable debug APK. Google Play distribution normally requires a signed release build and the Play Console publishing process. AppForge does not publish to Google Play for you.

Can I create an iPhone app or an offline app?

This builder currently creates Android APKs only. The app loads your live website, so it requires internet access; it is not an offline website exporter.

For security, never share your password, private API keys or account verification code. Your website address and selected logo images are sent to the build service to create your APK.
