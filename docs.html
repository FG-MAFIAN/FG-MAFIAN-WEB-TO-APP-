How to create and install an app with FG MAFIAN.

01

Enter your website

Use a public HTTPS website URL. Some websites block being displayed inside mobile apps, so test the preview first.

02

Customize the app

Choose an app name, valid Android package ID, icon, theme color and orientation.

03

Build the APK

Tap Build Installable APK. The connected GitHub Actions workflow compiles the Android application in the cloud.

Installing on Android

When the build completes, download the APK on your Android device, open it, and allow installation from your browser or file manager if Android asks. Only install APKs from sources you trust.

Sharing your app

After a successful build, use “Copy public download link” to copy a shareable URL. Anyone who has that URL can download the APK without signing in. The link stays available while the corresponding GitHub release and asset remain published.

Build requirements

The site must be connected to a GitHub repository with the required Actions workflow and Vercel environment variables. iPhone/iPad installation needs a separate Apple build and signing process.
